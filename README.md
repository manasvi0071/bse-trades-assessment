# BSE Trades Assessment

## Setup

### Backend
```bash
cd server
npm install
node index.js
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Open `http://localhost:5173`

## Usage

1. Click "Start Pull (10s test)" to simulate a fast pull.
2. Watch trades appear in real-time on the dashboard.
3. For the full 15-minute simulation, click "Start Pull (15 min)".
